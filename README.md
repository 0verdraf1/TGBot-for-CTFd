# 🤖 TGBot Maria — Бот для интеграции с CTFd

Асинхронный Telegram-бот на базе `aiogram 3`, предназначенный для автоматизации взаимодействия с платформой **CTFd**. Бот управляет регистрацией участников, выдачей учетных данных, синхронизацией игровых баллов и генерацией дипломов.

---

## 🏗 Архитектура и взаимодействие
Бот работает в связке с инфраструктурой CTFd, которая обычно развернута в Docker-контейнерах (`ctfd`, `nginx`, `db`). 
Бот подключается напрямую к базе данных **MariaDB** (используемой CTFd) для:
1. Создания пользователей в таблице `users`.
2. Чтения баллов из таблиц `solves` и `awards`.
3. Ведения собственной таблицы `users_bot` для расширенных данных профиля.

---

## ⚙️ Настройка Docker (MariaDB)

Чтобы бот мог подключаться к базе данных MariaDB, запущенной в Docker, необходимо правильно настроить сеть в вашем `docker-compose.yaml`. 

### Важное требование по сетям:
Для сервиса базы данных (`db`) в параметре `networks` должны быть указаны как внутренняя сеть (для связи с CTFd), так и внешняя/дефолтная (чтобы пробросить порт на хост или позволить боту достучаться до контейнера).

**Пример конфигурации в `docker-compose.yaml`:**

```yaml
services:
  db:
    image: mariadb:10.11
    restart: always
    environment:
      - MYSQL_ROOT_PASSWORD=password
      - MYSQL_USER=ctfd
      - MYSQL_PASSWORD=ctfd
      - MYSQL_DATABASE=ctfd
    volumes:
      - .data/mysql:/var/lib/mysql
    networks:
      - internal:
      - default:  # Позволяет боту достучаться через 127.0.0.1
    ports:
      - "127.0.0.1:3306:3306"
```

## 🚀 Установка и запуск

### 1. Подготовка окружения
1. Склонируйте репозиторий и создайте виртуальное окружение:
```bash
git clone <url_репозитория>
cd TGBot_maria
python -m venv venv
source venv/bin/activate  # Для Linux
venv\Scripts\activate     # Для Windows
pip install -r requirements.txt
```
2. **Важно:** Разработайте и разместите в корне проекта собственный файл `Соглашение.pdf` (согласие на обработку персональных данных). Бот отправляет этот файл пользователям при регистрации.

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
API_TOKEN=ваш_токен_бота
DATABASE_URL=mysql+aiomysql://username:password@127.0.0.1:3306/ctfd
ENV_ADMIN_IDS=12345678 87654321 # ID администраторов по умолчанию
ARCHITECT_ID=ваш_телеграм_id    # ID архитектора бота
```
> ⚠️ **Важно:** Пользователь с `ARCHITECT_ID` является суперадминистратором. Он может назначать и снимать других администраторов через меню бота. В целях безопасности рекомендуется назначать на эту роль только **одного** доверенного человека.

### 3. Генерация дипломов (Windows)
Для работы скрипта `templates_diplomas/create_diplomas.py` используется библиотека `docx2pdf`, которая требует установленного **Microsoft Word**. Скрипт берет данные из `table.xlsx`, заполняет `Sertificate.docx` и сохраняет результат в папку `Diplomas/`.

## 🛡 Запуск в режиме демона (Systemd)

Для обеспечения бесперебойной работы бота на Linux-сервере рекомендуется использовать `systemd`.

### 1. Создайте файл сервиса
```bash
sudo nano /etc/systemd/system/tgbot-maria.service
```

### 2. Вставьте следующий конфиг (замените пути на свои):
```ini
[Unit]
Description=Telegram Bot for CTFd Maria
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/TGBot_maria
ExecStart=/path/to/TGBot_maria/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### 3. Активируйте демона
```bash
sudo systemctl daemon-reload
sudo systemctl enable tgbot-maria
sudo systemctl start tgbot-maria
```

**Управление:**
- Проверить статус: `sudo systemctl status tgbot-maria`
- Посмотреть логи: `journalctl -u tgbot-maria -f`

## 🛠 Функционал бота
- **📝 Регистрация:** Сбор данных (ФИО, телефон, школа) и автоматическое создание аккаунта в CTFd.
- **🔑 Доступ:** Команда `/get_creds` выдает сгенерированный логин и пароль для входа на платформу.
- **📊 Рейтинг:** Автоматическое обновление баллов в БД бота на основе успехов в CTFd (каждые 5 минут).
- **🎓 Дипломы:** Выдача сертификатов в PDF формате после прохождения короткого опроса участником.
- **🚫 Модерация:** Система банов, апелляций и прямой связи с администрацией.
- **📢 Рассылка:** Админ-панель для массового оповещения участников.
